## 五、调试要点（供复现者避坑）

- **串口控制台**：nsh 与 ai_agent CLI 会**逐字符争抢**同一行输入（`help` 被切成 `hep`/`ple`）。
  驱动 CLI 请走 SSH 管道：`{ echo cmd; sleep N; } | ssh ... "ai_agent"`
- **`mediatool` 是测试工具，非产品路径**：其 `close` 命令不执行（缓冲区线程卡死），
  会造成"图槽位泄漏"的假象。判断 mediad 问题前先 `ps` 确认无残留 mediatool 进程
- **mediad 不能 `pkill` 后立即重启**：socket 仍被占（`EADDRINUSE`），只有断电重启能清
- **播放格式必须匹配 sink**：图不做 mono↔stereo 自动转换，手动测试要传 `<48k, stereo>`
- **`/etc` 打包源是 `src/etctmp/etc/`**，改完要删 `src/etctmp.c` 重新生成
